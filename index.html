/** * 교육관리 시스템 — 서버측 인증 * 안전보건점검 관리시스템의 auth.gs 와 같은 방식입니다. * * - 비밀번호는 절대 평문으로 저장하지 않습니다 (SHA-256 + 솔트, 반복 해시) * - 로그인하면 토큰을 발급하고 24시간 유지합니다 * - 모든 조회·저장 API 는 토큰을 확인한 뒤에만 동작합니다 * * 처음 한 번 * 1. INITIAL_ACCOUNTS 를 실제 담당자로 고친다 * 2. createInitialAccounts() 실행 * 3. 각자 첫 로그인 후 비밀번호를 바꾼다 (초기 비밀번호 표시가 사라짐) */ /** * 해시 반복 횟수 * Apps Script 는 SHA-256 한 번이 느려서 반복 횟수가 그대로 로그인 시간이 된다. * 1000회는 로그인에 5~8초가 걸려 "안 되는 것처럼" 보였다 → 250회(약 1초)로 낮췄다. * 솔트가 계정마다 다르고 시트는 개인 Drive 안에 있으므로 이 정도면 충분하다. * * 예전 1000회로 만든 비밀번호도 그대로 로그인된다. * 한 번 로그인하면 새 방식으로 조용히 다시 저장한다(아래 apiLogin_ 참고). */ var HASH_ROUNDS = 250; var LEGACY_ROUNDS = 1000; // 예전 계정 호환용 var TOKEN_HOURS = 24; // 토큰 유지 시간 /* 처음 만들 계정 — 사번을 아이디로 씁니다 */ var INITIAL_ACCOUNTS = [ { id: 'c01764', name: '천재우', dept: '안전보건팀', role: 'master', pw: 'chm2026!' }, { id: 'c04897', name: '이재혁', dept: '안전보건팀', role: 'user', pw: 'chm2026!' }, { id: 'c05651', name: '오혜지', dept: '경영지원', role: 'user', pw: 'chm2026!' } ]; /* ============================================================ * 계정 만들기 / 초기화 * ============================================================ */ function createInitialAccounts() { var made = [], kept = []; INITIAL_ACCOUNTS.forEach(function (a) { if (findUser_(a.id)) { kept.push(a.id); return; } createUser_(a.id, a.name, a.dept, a.role, a.pw, true); made.push(a.id + ' / ' + a.pw); }); var msg = '만든 계정:\n' + (made.join('\n') || '없음') + '\n이미 있던 계정: ' + (kept.join(', ') || '없음') + '\n\n※ 이 비밀번호를 각자에게 알려주고, 첫 로그인 후 바꾸게 하세요.'; Logger.log(msg); return msg; } function createUser_(id, name, dept, role, pw, temp) { var salt = Utilities.getUuid().replace(/-/g, ''); append_('_Users', { '아이디': id, '이름': name, '소속': dept || '', '권한': role || 'user', '비밀번호해시': hashPw_(pw, salt), '솔트': salt, '토큰': '', '토큰만료': '', '초기비밀번호': temp ? 'Y' : 'N', '상태': '사용', '최근로그인': '', '등록일시': new Date() }); log_('계정', id, '계정 생성'); } /** 비밀번호 초기화 — 관리자가 실행 */ function resetPassword(id, newPw) { var u = findUser_(id); if (!u) return '없는 아이디: ' + id; var salt = Utilities.getUuid().replace(/-/g, ''); update_('_Users', u._row, { '비밀번호해시': hashPw_(newPw, salt), '솔트': salt, '토큰': '', '토큰만료': '', '초기비밀번호': 'Y' }); log_('계정', id, '비밀번호 초기화'); return id + ' 초기화 완료 → ' + newPw; } /* ============================================================ * 해시 * ============================================================ */ function hashPw_(pw, salt, rounds) { var n = rounds || HASH_ROUNDS; var v = salt + '|' + String(pw); for (var i = 0; i < n; i++) { var raw = Utilities.computeDigest( Utilities.DigestAlgorithm.SHA_256, v, Utilities.Charset.UTF_8); v = Utilities.base64Encode(raw); } return v; } function findUser_(id) { var hit = null; rows_('_Users').forEach(function (r) { if (String(r['아이디']) === String(id)) hit = r; }); return hit; } /* ============================================================ * 로그인 / 토큰 * ============================================================ */ function apiLogin_(id, pw) { if (!id || !pw) return { ok: false, error: '아이디와 비밀번호를 입력하세요.' }; var u = findUser_(id); // 아이디가 없어도 같은 문구를 돌려준다 (있는 아이디인지 알려주지 않음) if (!u || u['상태'] !== '사용') { log_('로그인실패', id, '없는 아이디 또는 중지된 계정'); return { ok: false, error: '아이디 또는 비밀번호가 맞지 않습니다.' }; } if (hashPw_(pw, u['솔트']) !== u['비밀번호해시']) { /* 예전 1000회 방식으로 만든 계정이면 통과시키고, 새 방식으로 바꿔 둔다 */ if (hashPw_(pw, u['솔트'], LEGACY_ROUNDS) === u['비밀번호해시']) { update_('_Users', u._row, { '비밀번호해시': hashPw_(pw, u['솔트']) }); log_('계정', id, '해시 방식 자동 전환'); } else { log_('로그인실패', id, '비밀번호 불일치'); return { ok: false, error: '아이디 또는 비밀번호가 맞지 않습니다.' }; } } var token = Utilities.getUuid().replace(/-/g, ''); var exp = new Date(Date.now() + TOKEN_HOURS * 3600 * 1000); update_('_Users', u._row, { '토큰': token, '토큰만료': exp, '최근로그인': new Date() }); log_('로그인', id, '성공'); return { ok: true, token: token, user: { id: u['아이디'], name: u['이름'], dept: u['소속'], role: u['권한'], tempPw: u['초기비밀번호'] === 'Y' }, expires: exp.getTime() }; } /** 토큰 확인 — 통과하면 사용자 객체, 아니면 null */ function checkToken_(token) { if (!token) return null; var hit = null; rows_('_Users').forEach(function (r) { if (r['토큰'] && String(r['토큰']) === String(token)) hit = r; }); if (!hit) return null; if (hit['상태'] !== '사용') return null; var exp = hit['토큰만료']; if (!exp || new Date(exp).getTime() < Date.now()) return null; return { id: hit['아이디'], name: hit['이름'], dept: hit['소속'], role: hit['권한'], tempPw: hit['초기비밀번호'] === 'Y', _row: hit._row }; } function apiLogout_(token) { var u = checkToken_(token); if (u) { update_('_Users', u._row, { '토큰': '', '토큰만료': '' }); log_('로그아웃', u.id, ''); } return { ok: true }; } /** 본인 비밀번호 변경 */ function apiChangePw_(token, oldPw, newPw) { var me = checkToken_(token); if (!me) return { ok: false, error: '다시 로그인해 주세요.' }; if (!newPw || String(newPw).length < 6) { return { ok: false, error: '새 비밀번호는 6자 이상으로 정해주세요.' }; } var u = findUser_(me.id); if (hashPw_(oldPw, u['솔트']) !== u['비밀번호해시'] && hashPw_(oldPw, u['솔트'], LEGACY_ROUNDS) !== u['비밀번호해시']) { return { ok: false, error: '현재 비밀번호가 맞지 않습니다.' }; } var salt = Utilities.getUuid().replace(/-/g, ''); update_('_Users', u._row, { '비밀번호해시': hashPw_(newPw, salt), '솔트': salt, '초기비밀번호': 'N', '토큰': '', '토큰만료': '' // 바꾸면 다시 로그인 }); log_('계정', me.id, '비밀번호 변경'); return { ok: true, message: '비밀번호를 바꿨습니다. 다시 로그인해 주세요.' }; } /* ============================================================ * 계정 관리 (마스터 전용) * ============================================================ */ function apiUserList_(token) { var me = checkToken_(token); if (!me) return { ok: false, error: '다시 로그인해 주세요.' }; if (me.role !== 'master') return { ok: false, error: '권한이 없습니다.' }; var list = rows_('_Users').map(function (r) { return { id: r['아이디'], name: r['이름'], dept: r['소속'], role: r['권한'], state: r['상태'], tempPw: r['초기비밀번호'] === 'Y', lastLogin: r['최근로그인'] ? new Date(r['최근로그인']).getTime() : 0 }; }); return { ok: true, users: list }; } function apiUserSave_(token, p) { var me = checkToken_(token); if (!me) return { ok: false, error: '다시 로그인해 주세요.' }; if (me.role !== 'master') return { ok: false, error: '권한이 없습니다.' };
